# Parsons Photography Minor info page

A static information page for the Photography Minor at Parsons, built with Astro and Markdown and deployed through GitHub Pages.

**[Open the website](https://taipinc.github.io/photo-minor-info/)**

## Documentation

- [Application README and local setup](photo-minor-info/README.md)
- [Editing announcements, courses, and images](photo-minor-info/docs/CONTENT.md)
- [Maintenance and deployment](photo-minor-info/docs/MAINTENANCE.md)
- [Architecture and design decisions](photo-minor-info/docs/ARCHITECTURE.md)
- [Agent instructions](photo-minor-info/AGENTS.md)

The Astro application is in `photo-minor-info/`. The active GitHub Pages workflow is `.github/workflows/deploy.yml` at this repository root.

The [official Photography Minor program webpage](https://www.newschool.edu/undergrad-minors/photography/) remains the authoritative source for program requirements and information. Spring 2027 course availability in this site's initial release is demonstration data, as documented in the editing guide.
